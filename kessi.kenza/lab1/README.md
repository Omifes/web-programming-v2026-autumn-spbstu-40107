# Лабораторная работа 1

## Задание

Создать три карточки товара (вариант 33). Каждая карточка должна быть
представлена div-блоком, содержащим изображение (200x150px), заголовок (Arial,
18px, bold) и описание (Arial, 14px). Карточки должны располагаться в одну
строку с отступом 20px. Для всех элементов используется padding: 10px.

## Реализация

Решение реализовано на чистом HTML5 и CSS3. Контейнер выстроен горизонтально с
использованием CSS Flexbox (`display: flex; gap: 20px;`). Место изображения
(200x150px) в карточке занимает div-блок `.product-image`, так как файлы
изображений не прилагаются. Шрифты и размеры заданы строго по спецификации
варианта.

## Запуск

Открыть файл `index.html` в веб-браузере.
