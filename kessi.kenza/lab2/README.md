# Лабораторная работа 2

## Задание

Реализовать функцию `countVowels(str)` (вариант 33), которая возвращает
количество гласных букв (a, e, i, o, u) в строке без учёта регистра.

## Реализация

Функция проверяет входящую строку, преобразует символы в нижний регистр и
считает количество гласных с помощью структуры данных `Set`. Логика завернута в
ES-модуль с именованным экспортом.

## Запуск

Запустить скрипт в среде с поддержкой ES-модулей (например, Node.js).
