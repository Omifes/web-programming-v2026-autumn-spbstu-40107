# Лабораторная работа 3

## Задание

Реализуйте функцию `shuffleArray(arr)` (вариант 33), которая перемешивает
элементы массива в случайном порядке.

## Реализация

Использован алгоритм тасования Фишера-Йетса. Оригинальный входящий массив
копируется с помощью spread-оператора, чтобы избежать изменения входных данных.
Функция возвращает перемешанный клон исходного массива.

## Запуск

Запустить скрипт в среде с поддержкой ES-модулей (например, Node.js).
