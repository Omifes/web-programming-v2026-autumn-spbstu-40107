# Лабораторная работа 4

## Задание

Реализовать класс Recipe и интерфейс управления списком рецептов с асинхронными
операциями, сохранением состояния в LocalStorage и функциями агрегации данных.

## Реализация

Создан класс `Recipe` с полями для названия, ингредиентов и шагов приготовления,
а также методами добавления и удаления элементов. Реализованы функции
группировки рецептов по числу ингредиентов и длине шагов, поиск по ингредиенту,
получение уникального списка ингредиентов и названий рецептов. Интерфейс
адаптирован под контракт тестов, операции добавления и удаления выполняются
асинхронно с сохранением состояния в LocalStorage.

## Запуск

Открыть `index.html` в браузере или через локальный веб-сервер.
