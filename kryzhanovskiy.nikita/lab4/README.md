# Лабораторная работа 4

## Задание

Реализовать класс Recipe и интерфейс управления списком рецептов с асинхронными
операциями, сохранением состояния в LocalStorage и функциями агрегации данных.

## Реализация

Создан класс `Recipe` с инкапсуляцией данных о названии, ингредиентах и шагах
приготовления. Реализованы функции группировки по числу ингредиентов и длине
шагов, поиск по ингредиенту, получение списка уникальных ингредиентов и названий
рецептов. Пользовательский интерфейс динамически перерисовывается при любых
мутациях модели данных. Все операции добавления и удаления выполняются
асинхронно через Promise с таймером. Данные сохраняются в LocalStorage.

## Запуск

Открыть `index.html` в браузере или через Live Server. Импорт класса и
вспомогательных функций:

```javascript
import {Recipe, getUniqueIngredients} from './model.js';
```
